# a2a-lab-LAB

Demo-tier standalone app: A2A nested-act delegation — a generalist agent hands a task to a specialist sub-agent and the full chain stays attributable. Two mock RFC 8693 exchanges build `act={specialist, act:{generalist}}` with scope narrowed per hop; the gateway routes the call only when the SPECIALIST is registered (UC2.6 PERMIT_THEN_DENY). Standalone mock of the AI-DEMO2 A2A track (UC2 / UC2.5 / UC2.6 / UC2.7, the `a2aDelegationService` chained exchange and `GatewayTokenPolicy`).

- Run: `./scripts/run.sh` (http://localhost:7700). Test: `npm test` (server is `node --test test/*.test.js`, a glob; web is vitest). Preflight: `npm run doctor`. Docker: `HOST_PORT=7700 docker compose up --build -d` (published on 127.0.0.1 only). Ports 7700-7709 (`server/src/safety.js`). Node 26 only. Through the shared lab-proxy: `https://local.ping-devops.com:8443/a2a-lab/`.
- Core: `server/src/a2a.js` (the nested-act delegation engine: Agent Card registry, RFC 8693 exchange #1 and #2, chain depth, scope narrowing, the `GatewayTokenPolicy` mock — nested chains of depth >= 2 skip the exchanger actor allow-list, an unregistered specialist is DENIED). Story data `server/src/policyData.js` with `{{token}}` text filled by `cast.js` (3 vertical packs); a test fails on an undefined token.
- API: `GET /api/a2a/agent-card`, `GET /api/registry` + `POST /api/registry/set` (seeded: `portfolio-specialist`, `wire-specialist`), `POST /api/exchange/one` (user token + generalist actor -> `act={generalist}`), `POST /api/exchange/two` (generalist token + specialist actor -> the nested chain), `POST /api/tool` (the gated specialist call: 200 PERMIT / 403 DENY `unregistered_specialist` / 401 `missing_bearer` / 403 `chain_not_nested`), `GET /api/run-observability` (rule 27; Mock only, Real answers 409), `GET /api/runs`, `POST /api/reset`, `GET /api/scenarios`, `GET /api/diagram`, `GET /api/info`, `POST /api/mode` (rule 19; Real is RESERVED — configured env reported, no live data path), `GET /api/health` (`demo-health/1`). Workspace id in `X-Workspace`.
- Decision contract (do not weaken): authorization keys on WHO is acting (the registered specialist identity), not just who they act for; the specialist holds only the scope the handoff granted; the full chain stays attributable in the token; depth >= 2 chains skip the exchanger allow-list because the PDP validates the chain.
- Rules that bite: loopback bind only; same-origin writes; zero outbound network (netguard); only `.example`/`.invalid` hosts; every token and decision value shown raw and labelled mock; `POST /api/mode` is exactly `{ source: "mock"|"real" }`.
- Web: `web/src/App.jsx` (tabs, presenter, Reset, X-Workspace via `workspace.js`), shared diagram kit, talk track, verify mark. Colours come from `tokens.css` only. Test: `npm test -w web` (vitest + RTL, mocked fetch).
- Trace: `server/src/trace.js` builds W3C traceparent for every mock hop.
- Attribution: scaffold copied from hitl-mfa-lab-LAB and mcp-gateway-lab-LAB (fork rule 4); every surface here is this lab's own. No cross-repo imports.
- Run observability (rule 27): `web/src/run-observability/` and `server/src/runObservability.js` are vendored byte for byte (pin `run-observability.sha256`, test `scripts/run-observability.pin.test.mjs`); never edit them, change the canonical in AI-DEMO-Standalone and re-vendor. Lab side: `server/src/runObs.js` (decision line, current-run slice, record builder), events per workspace in `workspaces.js`, `RunObs` in `PolicyGate.jsx`. Every decision point calls `observe()` in `app.js`, which writes one stdout line and one event; a mock row must come from an event the mock computed.
